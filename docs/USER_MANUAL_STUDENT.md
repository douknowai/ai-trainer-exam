# 学员操作手册

1. 使用学校发放的账号登录；首次登录按提示修改密码。
2. 先完成“电脑基础”或练习模块，熟悉点击、拖拽、删除、输入和音频播放。
3. 练习期间可查看提示、反馈和错题；到练习锁定时间后系统会自动关闭练习入口。
4. 正式考试前检查浏览器、网络、声音和屏幕分辨率。
5. 点击“进入考试”后，倒计时以服务器时间为准。答案会自动保存，刷新后可恢复。
6. 实操题只在系统内的虚拟工作区操作，不需要修改电脑真实文件。
7. 音频转写要保留题目要求的“嗯、啊、哦”等语气助词。
8. 提交前检查未答题。到时系统会自动交卷；交卷成功后保存回执。
9. 成绩由学校统一发布，交卷后不会提前显示答案或分数。
10. 断网时不要反复刷新，等待网络恢复；无法恢复时立即联系监考人员登记异常。
