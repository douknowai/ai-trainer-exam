## 当前执行环境限制

当前容器无法访问 npm registry，原始 ZIP 未包含 `node_modules`，因此无法在本交付环境真实执行：

- `pnpm install --frozen-lockfile`
- 完整 `tsc` 类型检查
- ESLint、Stylelint
- Vitest 全量测试
- Next.js 生产构建
- Supabase 真实迁移和数据库 API 集成
- S3、image2-api、mimo-lecture-audio-skill、Coze fallback 联调
- 浏览器 E2E、弱网和并发压测

仓库已提供 `.github/workflows/ci.yml` 和 `pnpm validate`。上述检查必须在联网的目标工作区完成。

1. 安装依赖后执行 `pnpm validate`。
2. 在测试数据库运行全部迁移、核心种子和实操种子。

4. 教师 E2E：班级、布置练习、进度、错题分析、成绩查看。
5. 管理员 E2E：题库导入、审核、组卷、考期、监考、复核、发布和审计。
6. 权限矩阵及跨机构 IDOR 测试。
7. 断网30—120秒恢复和重复交卷幂等测试。
8. 按真实招生规模执行并发自动保存、心跳和交卷压测。
9. image2、mimo、Coze fallback、S3签名读取和素材冻结联调。
10. Chrome/Edge及1366×768机房可用性测试。

在上述验收全部通过前，版本状态为“生产候选版”，不应直接用于不可重考的正式考试。
