# 生产化修复报告

本次升级以深度审计报告为基线，处理认证、API 契约、评分安全、时间锁、题库隔离、交卷事务、正式实操评分、成绩发布、多机构越权、种子脚本、素材、测试和文档问题。

## 关键修复

- Token 存储统一，修复 Bearer null。
- apiFetch 统一序列化与响应解包。
- 移除客户端 graderId，服务端 taskType 绑定评分器。
- 统一 0—1 评分比例与真实项目分值。
- 服务端强制练习锁定。
- 考试题仅来自冻结的考试试卷。
- questions/start/save/heartbeat/submit 校验报名、attempt、时间和所有权。
- 交卷事务化和幂等化。
- 正式考试接入理论及全部实操评分器。
- 交卷后只返回回执，成绩等待发布。
- 修复成绩状态、复核字段与部分调整覆盖问题。
- 所有管理资源增加机构范围校验。
- 试卷拒绝练习专用、未发布和跨机构内容。
- 重写安全种子脚本，补齐离线素材。
- 增加媒体 Provider、S3、checksum、审核和冻结流程。
- 增加 CI、单元回归测试、安全文档和部署手册。
