# 管理员操作手册

## 初始化

创建机构、培训项目、班级、教师和学员。分配角色时遵循最小权限；教师仅授权到具体班级。

## 题库

练习库与考试库独立管理。DOCX 导入后先处理重复、答案缺失、超纲、法律时效和格式问题。考试题必须审核发布并确认 `eligible_for_formal_exam=true`。

## 实操任务

分别建立 Excel 删行、文件分类、图片清洗、图片标注、文本情感、音频转写和统计填表任务。标准答案使用稳定 row_id/asset_id 和归一化图片坐标。

## 素材

通过素材工坊生成或上传素材，核对内容与标准答案，填写审核意见。音频发布前必须确认标准转写。只有 `reviewed` 素材可以冻结发布。

## 试卷与考务

从已发布考试库内容创建试卷。发布试卷后不得无痕修改。创建考试安排时设置练习开放/锁定、考试开始/结束、迟到入场、交卷宽限和成绩发布时间。

## 成绩

系统自动评分后，管理员检查异常、进行复核并填写理由。人工调整保存原始分、调整分、最终分和审计记录。确认无误后统一发布。

## 事故处理

发现掉线、设备故障、异常交卷或评分争议时记录考生、时间、attempt、现象和处理人。不得直接修改数据库；使用复核与重评分流程。
