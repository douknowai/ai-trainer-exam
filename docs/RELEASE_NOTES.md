# 1.0.0-rc.2 发布说明

本版本以 `docs/AUDIT_BASELINE.md` 中记录的深度审计问题为基线，完成认证、API契约、确定性评分、练习锁定、正式题库隔离、考试状态和截止时间、自动保存、事务交卷、成绩发布、多机构权限、题库导入、素材冻结、数据库迁移和安全种子的系统性重构。

RC.2 在核心修复基础上补齐了教师端班级、练习布置、学习进度、错题分析和成绩页面，新增真实培训项目管理，修复学员考试续考进入规则、成绩状态显示及若干数据库字段一致性问题，并完成最终离线质量检查和交付清单。

该版本是生产候选版。完整上线条件见 `TEST_REPORT.md` 和 `DELIVERY_MANIFEST.md`。
