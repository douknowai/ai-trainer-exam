## 上线前强制验收

当前交付环境无法访问 npm registry，原仓库也未包含 `node_modules`，因此无法在此处完成完整依赖安装、Next.js构建、Vitest、Supabase、S3和浏览器联调。目标 Coze 工作区必须依次执行：

```bash
pnpm install --frozen-lockfile
pnpm validate
pnpm db:migrate
pnpm db:seed-core
pnpm db:seed-tasks
```

然后执行真实数据库、对象存储、媒体 Provider、角色权限、弱网恢复、并发交卷、Chrome/Edge和1366×768机房验收。验收完成前，本版本应标记为“生产候选版”，不用于不可重考的正式考试。
